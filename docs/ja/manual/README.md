# 利用マニュアル（Pマーク編）

OpenGRC で Pマーク（JIS Q 15001:2023）を運用するための手順書です。初めて使う人が、組織の準備から文書の整備までを一人で進められるように書いています。

| 章 | 内容 | 状態 |
| --- | --- | --- |
| [1. 導入編](01-setup.md) | 組織の作成、ユーザーの招待、Pマーク・ISO 27001 のフレームワークと内部統制の取り込み | 公開 |
| [2. 文書編](02-documents.md) | 設定ファイルの書き方、文書の作成・登録・紐付け、承認・公開・署名、改訂 | 公開 |
| [3. 年間の運用編](03-operations.md) | 個人情報管理台帳、リスク評価、教育、内部監査、委託先の評価、マネジメントレビュー、是正 | 一部公開（3.1 台帳、3.2 リスク分析表、3.3 教育、3.4 内部監査、3.5 委託先の評価） |
| 4. 審査対応編 | 申請・審査で求められる記録と、その出力方法 | 準備中 |

## 用語

画面と文書で使う用語は、[訳語表](../glossary.md) と [用語解説](../terms.md) にまとめています。

## このマニュアルの前提

- OpenGRC の管理画面（コンソール）に、オーナーまたは管理者の役割でログインできること
- 文書を作る作業（第 2 章）は、このリポジトリを手元に取得し、Go（`go.mod` に書かれたバージョン）と Node.js（`.nvmrc` に書かれたバージョン）が使えるパソコンで行います
- ボタンや項目の名前は、画面の日本語表示に合わせています。画面の更新で名前が変わった場合は、このマニュアルも直します
