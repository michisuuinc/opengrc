# 1. 導入編

組織を作り、使う人を招待し、Pマークの要求事項（フレームワーク）と、それを満たすための社内の取り組み（内部統制）を取り込みます。ここまで終えると、第 2 章で文書を作って紐付けられる状態になります。

## 1.1 組織を作る

1. 管理画面にログインします。
2. 「組織を作成」を選び、会社名を入れて作成します。

組織は会社ごとに 1 つ作ります。以降の操作は、すべてこの組織の中で行います。

### メールの言語を日本語にする

招待やお知らせのメールは、受け取る人の言語で送られます。言語は次の順に決まります。

1. 本人が保存した言語。管理画面を開くと、画面の言語（ブラウザの言語）が自動で保存されます。コンプライアンスポータルで言語を切り替えた場合も保存されます。
2. SCIM で連携した人は、ID 管理側の言語の設定
3. 組織の **メールの既定の言語**
4. どれもなければ英語

最初の招待メールの時点では、本人の言語はまだわかりません。日本語で届くように、組織を作ったら次の設定をしておきます。

1. 管理画面の **設定** → **一般** を開きます。
2. **メールの言語** で **日本語** を選び、**保存** を押します。

外部の署名者やアップデートの購読者など、アカウントのない人へのメールも、この言語になります。なお、新規登録（サインアップ）の確認メールだけは英語で届きます。

## 1.2 ユーザーを招待する

1. メニューの「ID・アクセス管理（IAM）」から「ユーザー」を開きます。
2. 「ユーザーを追加」で、招待する人のメールアドレスと役割を入れます。招待のメールが届き、本人が承諾すると使えるようになります。

役割は、Pマークの体制に合わせて次のように割り当てます。

| 役割 | できること | 割り当てる人の例 |
| --- | --- | --- |
| オーナー | すべての機能 | 代表者、個人情報保護管理者 |
| 管理者 | 組織の設定と API キー以外のすべての機能 | 個人情報保護管理者の代行者、情報システム担当者 |
| 監査人 | 設定とタスク以外の閲覧 | 個人情報保護監査責任者、監査員 |
| 閲覧者 | 閲覧のみ | 内容を確認するだけの人 |
| 従業員 | 従業員ページ（方針・規程の確認と署名など） | すべての従業者 |

- 個人情報保護監査責任者は、監査する対象（運用）を自分で変えられないよう、監査人の役割にすることをおすすめします。
- 従業者には、方針・規程への署名を依頼します（第 2 章）。従業員の役割で招待しておきます。

## 1.3 フレームワークを取り込む

Pマークの要求事項（JIPDEC の「構築・運用指針」の J 番号ごとの項目）を、フレームワークとして取り込みます。ISO 27001 も同時に運用する場合は、あわせて取り込みます。

1. メニューの「フレームワーク」を開き、「新しいフレームワーク」を押します。
2. 一覧から取り込むフレームワークを選びます。画面が日本語のときは、日本語版がある ISO 27001・ISO 27701 は日本語版が取り込まれます。

   | フレームワーク | 一覧の名前 |
   | --- | --- |
   | プライバシーマーク（JIS Q 15001:2023） | PrivacyMark (JIS Q 15001:2023) |
   | ISO 27001（2022） | ISO 27001 (2022) |
   | ISO 27701（2025） | ISO 27701 (2025) |

   一覧にないファイル（自社で作ったフレームワークなど）は、「インポート」でファイルを選んで取り込みます。
3. 「フレームワークをインポートしました」と表示されたら完了です。Pマークは 59 項目になります。

## 1.4 内部統制を取り込む

内部統制は、要求事項を満たすために社内で行う取り組み（「個人情報の特定と台帳管理」「従業者教育の実施と記録」など）です。Pマークと ISO 27001 の両方の項目に紐付いた 39 件を用意しています。それぞれに、実施する作業と、審査で求められる証跡（記録）が設定されています。

1. 先に 1.3 で、Pマークのフレームワークを取り込んでおきます。内部統制は、取り込み済みのフレームワークの項目に紐付けられます。ISO 27001 の項目にも紐付けたい場合は、ISO 27001 も先に取り込みます。
2. メニューの「内部統制」を開き、「インポート」で次のファイルを選びます。

   `apps/console/public/data/internal-controls/jp/pmark-iso27001-2022.json`

3. 「内部統制をインポートしました。」と表示されたら完了です。

## 1.5 確認

- 「フレームワーク」で Pマークを開き、各項目に内部統制が紐付いていることを確かめます。
- 「内部統制」で任意の 1 件を開き、作業と求める証跡が表示されることを確かめます。
