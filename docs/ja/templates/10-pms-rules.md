※ この規程は、個人情報保護マネジメントシステム（以下「PMS」という）の体制、計画、運用、評価、改善を定める中心の規程です。取得・利用・提供などの個別のルールは、ほかの規程に分けています。
※ 小規模な会社を想定しています。部門が 1 つしかない場合は「部門責任者」を個人情報保護管理者が兼ねるなど、実態に合わせて書き換えてください。

## 第1章 総則

### 第1条（目的）

この規程は、【会社名】（以下「当社」という）が取り扱う個人情報を適切に保護するため、PMS を確立し、実施し、維持し、継続的に改善するために必要な事項を定める。

### 第2条（適用範囲）

1. この規程は、第7条で定める PMS の適用範囲において、当社が取り扱うすべての個人情報に適用する。
2. この規程は、当社の役員、正社員、契約社員、パートタイマー、アルバイト、派遣社員など、当社の指揮監督を受けて業務に従事するすべての者（以下「従業者」という）に適用する。

### 第3条（用語の定義）

この規程で使う用語の意味は、次のとおりとする。ここにない用語は、個人情報の保護に関する法律（以下「個人情報保護法」という）の定義による。

| 用語 | 意味 |
| --- | --- |
| 個人情報 | 生存する個人に関する情報で、氏名、生年月日その他の記述等により特定の個人を識別できるもの（ほかの情報と容易に照合でき、それにより特定の個人を識別できるものを含む）、または個人識別符号を含むもの |
| 本人 | 個人情報によって識別される特定の個人 |
| 要配慮個人情報 | 人種、信条、社会的身分、病歴、犯罪の経歴、犯罪により害を被った事実など、本人に対する不当な差別や偏見が生じないよう取扱いに特に配慮が必要な個人情報 |
| 保有個人データ | 当社が開示、内容の訂正・追加・削除、利用の停止、消去、第三者への提供の停止を行う権限を持つ個人データ |
| 個人関連情報 | 生存する個人に関する情報で、個人情報、仮名加工情報、匿名加工情報のいずれにも当たらないもの（Cookie などの識別子に結び付いた閲覧履歴など） |
| 委託先 | 当社が個人情報の取扱いの全部または一部を委託する外部の事業者 |
| 開示等の請求等 | 本人からの利用目的の通知、開示、訂正・追加・削除、利用停止・消去、第三者提供の停止、第三者提供記録の開示の請求または求め |
| 個人情報保護管理者 | 代表者から任命され、PMS の実施と運用に責任と権限を持つ者 |
| 個人情報保護監査責任者 | 代表者から任命され、内部監査の実施と報告に責任と権限を持つ者 |
| 不適合 | この規程、関連規程、法令等の要求を満たしていないこと |
| 是正処置 | 不適合の原因を取り除き、再発を防ぐための処置 |
| このシステム | 当社が PMS の運用に使う GRC 管理システム。台帳、リスク、監査、文書などを記録する |

## 第2章 組織の状況と適用範囲

### 第4条（組織とその状況の把握）（J.1.1）

1. 個人情報保護管理者は、当社の事業内容、個人情報を取り扱う業務、PMS に影響する外部・内部の課題を洗い出し、文書にまとめる。
2. 前項の文書は、年 1 回以上、および事業内容や組織に大きな変化があったときに見直す。

### 第5条（利害関係者のニーズと期待の把握）（J.1.2）

個人情報保護管理者は、本人（顧客、従業者、応募者など）、取引先、委託先、監督官庁などの利害関係者と、それぞれが当社の個人情報の取扱いに求める事項を一覧にする。一覧は、前条第1項の文書とあわせてこのシステムの「ドキュメント」で管理する。

### 第6条（法令等の特定）（J.1.3）

1. 個人情報保護管理者は、当社が守るべき法令、国が定める指針（ガイドライン）、業界団体の規範、契約上の義務（以下「法令等」という）を特定し、「法令等一覧」にまとめる。
2. 法令等一覧には、少なくとも次の項目を記載する。
   - 名称と所管（制定者）
   - 当社に関係する主な要求事項
   - 関係する部門・業務
   - 確認日
3. 個人情報保護管理者は、年 1 回以上、および法令等の改正を知ったときに法令等一覧を見直し、必要に応じて規程や手順を改訂する。見直しの結果は、このシステムの「ドキュメント」に記録する。
4. 法令等の改正情報は、個人情報保護委員会のWebサイト、業界団体からの通知などで入手する。

※ 法令等一覧には、少なくとも個人情報保護法、同法施行令、同法施行規則、個人情報保護委員会のガイドライン（通則編、外国にある第三者への提供編、第三者提供時の確認・記録義務編、仮名加工情報・匿名加工情報編）、JIS Q 15001、業種別のガイドライン（該当する場合）、マイナンバー法（特定個人情報を扱う場合）を含めてください。
※ 2026 年に成立・公布された改正個人情報保護法は、この規程の制定時点では施行前です。改正法の施行時に見直す（課徴金制度の導入、漏えい等が起きたときの本人への通知の扱いなど）。

### 第7条（PMS の適用範囲）（J.1.4）

1. PMS の適用範囲は、【適用範囲】とする。

※ 例：「当社の全事業、全従業者、本社（【所在地】）で取り扱うすべての個人情報」
2. 適用範囲は、第4条から前条までの結果を踏まえて決定し、代表者の承認を得て文書にする。
3. 適用範囲は、年 1 回以上、および事業所や事業の追加・廃止があったときに見直す。

※ Pマークは原則として法人全体が対象です。一部の事業所や部門を除外する場合は、JIPDEC の審査基準で認められるかを事前に確認してください。

### 第8条（PMS の確立と運用）（J.1.5）

当社は、この規程と第27条に定める内部規程に従って PMS を確立し、実施し、維持し、継続的に改善する。

## 第3章 リーダーシップと体制

### 第9条（代表者の責任）（J.2.1）

代表者は、PMS に関して次の事項を行う。

1. 個人情報保護方針を定め、内外に示す。
2. 個人情報保護管理者と個人情報保護監査責任者を任命する。
3. 目標と年間計画を承認する。
4. PMS の運用に必要な資源（人、予算、時間、設備）を確保する。
5. マネジメントレビューを実施し、改善を指示する。
6. 従業者に、PMS に従うことの重要性を伝える。

### 第10条（個人情報保護方針）（J.2.2）

1. 代表者は、内部向けと外部向けの個人情報保護方針を定める。内容は『個人情報保護方針（内部向け）』（02）と『個人情報保護方針（外部向け）』（01）による。
2. 内部向けの方針は、文書にして全従業者に周知し、従業員ポータルで確認の署名を得る。
3. 外部向けの方針は、当社のWebサイトに掲載するなど、本人が容易に知ることのできる状態に置く。
4. 方針は、マネジメントレビューのときに見直す。

### 第11条（体制と役割）（J.2.3.1）

PMS の体制と主な役割は、次のとおりとする。体制図はこのシステムの「ドキュメント」で管理する。

| 役割 | 担当者 | 主な責任と権限 |
| --- | --- | --- |
| 代表者 | 【代表者氏名】 | 第9条と第10条に定める事項。PMS の最終責任を持つ |
| 個人情報保護管理者 | 【個人情報保護管理者】 | PMS の実施と運用の統括、規程の整備、台帳とリスクの管理、教育の計画、委託先の監督、事故・苦情・開示等の請求への対応の統括、代表者への報告 |
| 個人情報保護監査責任者 | 【個人情報保護監査責任者】 | 内部監査の計画、監査員の選定、実施、報告 |
| 部門責任者 | 【部門責任者】 | 部門内での規程の実施、部門の個人情報の特定、運用の確認、部門の従業者の監督 |
| 苦情・相談窓口 | 【問合せ窓口】 | 本人からの苦情・相談、開示等の請求等の受付 |
| 従業者 | 全従業者 | 規程に従った個人情報の取扱い、事故や違反のおそれの報告 |

### 第12条（個人情報保護管理者と個人情報保護監査責任者の任命）（J.2.3.2）

1. 代表者は、役員または管理職の中から個人情報保護管理者を任命する。
2. 代表者は、個人情報保護監査責任者を任命する。個人情報保護監査責任者は、個人情報保護管理者を兼ねてはならない。
3. 任命は任命書で行い、このシステムの「ドキュメント」に記録する。
4. 個人情報保護管理者が不在のときに代行する者を、あらかじめ【代行者】と定める。

※ 個人情報保護監査責任者を代表者が兼ねることの可否は、審査機関の考え方を確認してください。独立性を保つため、管理者・代表者以外の者を任命するのが無難です。

### 第13条（管理目的と管理策の決定）（J.2.4）

個人情報保護管理者は、リスクアセスメントの結果を踏まえ、JIS Q 15001 の管理目的と管理策を参照して当社が実施する管理策を決める。決めた管理策は、このシステムの「内部統制」に登録し、J 番号と紐付ける。

## 第4章 計画

### 第14条（個人情報の特定）（J.3.1.1）

1. 部門責任者は、自部門の業務で取り扱う個人情報を、業務の単位ごとに洗い出す。
2. 個人情報保護管理者は、洗い出した結果を個人情報管理台帳（以下「台帳」という）にまとめる。台帳は、このシステムの「処理活動」で管理する。
3. 台帳には、少なくとも次の項目を記載する。
   - 業務の名称と担当部門
   - 個人情報の項目と、要配慮個人情報の有無
   - 本人の種類（顧客、従業者、応募者など）と、おおよその件数
   - 利用目的
   - 取得の方法（本人から書面で直接、Webフォーム、第三者からの提供など）
   - 保管の場所と媒体（システム名、書庫など）
   - アクセスできる人の範囲
   - 保存期間と廃棄の方法
   - 委託・第三者提供・共同利用・外国への移転の有無と相手
4. 台帳は、年 1 回以上、および業務の追加・変更・廃止があったときに見直す。見直したときは、見直した日と実施者を記録する。

### 第15条（リスクと機会への取り組み）（J.3.1.2）

個人情報保護管理者は、第4条と第5条で洗い出した課題と期待を踏まえ、PMS が成果を上げることを妨げるリスクと、改善につながる機会を特定し、目標と年間計画に反映する。

### 第16条（リスクアセスメント）（J.3.1.3）

1. 個人情報保護管理者は、台帳の個人情報ごとに、取得・入力、移送・送信、利用・加工、保管・バックアップ、消去・廃棄の各段階で起こりうるリスクを洗い出す。リスクには、漏えい、滅失、き損、目的外利用、不正な取得、法令等への違反、本人の権利利益の侵害を含める。
2. 洗い出したリスクは、発生可能性と影響度で評価し、対応の要否と優先度を決める。評価の基準は『リスク評価基準』【文書番号】による。
3. リスクアセスメントは、年 1 回以上、および次の場合に実施する。
   - 新しい業務やシステムで個人情報を取り扱うとき
   - 業務の流れ、委託先、保管場所を変えるとき
   - 漏えい等の事故や重大な不適合が起きたとき
   - 法令等が改正されたとき
4. リスクアセスメントの結果は、このシステムの「リスク」に記録し、台帳（処理活動）と紐付ける。

### 第17条（リスク対応）（J.3.1.4）

1. 個人情報保護管理者は、評価したリスクごとに対応方針（低減、受容、回避、移転）と対策を決め、このシステムの「リスク」にリスク対応計画として記録する。
2. 対策をとった後に残るリスク（残留リスク）は、個人情報保護管理者が確認し、受容してよいかを判断して承認する。承認の記録は「リスク」に残す。
3. 残留リスクのうち、受容の判断に経営判断が必要なものは代表者の承認を得る。
4. 対策の実施は、このシステムの「タスク」に担当者と期限を付けて登録し、進捗を管理する。

### 第18条（目標と年間計画）（J.3.2、J.3.3）

1. 個人情報保護管理者は、毎年【年間計画を作る月】に、個人情報保護の目標と年間計画を作り、代表者の承認を得る。
2. 目標は、測定できるもの（例：教育の受講率【教育の受講率の目標】、内部監査の不適合の是正完了率、事故件数）とし、達成の期限と担当者を定める。
3. 年間計画には、少なくとも次の事項と実施時期を定める。
   - 台帳の見直しとリスクアセスメント
   - 従業者の教育
   - 運用の確認と点検
   - 委託先の評価
   - 内部監査
   - マネジメントレビュー
   - 法令等一覧の見直し
4. 年間計画と目標の達成状況は、このシステムの「ドキュメント」と「タスク」で管理する。

### 第19条（変更の計画）（J.3.4）

体制、業務の流れ、システム、委託先などを変更するときは、個人情報保護管理者が変更の目的、影響、必要な資源、担当者、時期を定めた計画を作り、変更によるリスクを第16条に従って評価してから実施する。

## 第5章 支援

### 第20条（資源）（J.4.1）

代表者は、年間計画の実施に必要な人員、予算、設備、外部の専門家の支援を確保する。

### 第21条（力量）（J.4.2）

1. 個人情報保護管理者、個人情報保護監査責任者、監査員、部門責任者に必要な知識と経験は、『教育規程』（16）で定める。
2. 力量の評価と、不足する場合の教育は、『教育規程』（16）による。

### 第22条（認識）（J.4.3）

全従業者が、方針、自分の役割、規程に違反した場合の結果を理解するよう、『教育規程』（16）に従って教育を行う。

### 第23条（コミュニケーション）（J.4.4.1）

1. 個人情報保護管理者は、PMS に関する社内外への連絡について、内容、時期、相手、方法、担当者を「連絡体制の一覧」に定める。
2. 一覧には、少なくとも次の連絡を含める。
   - 従業者への方針・規程の周知と改訂の通知
   - 事故・違反の社内報告の経路
   - 本人からの苦情・相談、開示等の請求等の受付と回答
   - 委託先との連絡
   - 個人情報保護委員会、認定個人情報保護団体、JIPDEC などへの報告

### 第24条（緊急事態への準備）（J.4.4.2）

漏えい、滅失、き損などの事故が起きたとき、またはそのおそれがあるときの対応は、『漏えい等の緊急時対応手順』（15）による。個人情報保護管理者は、手順を全従業者に周知し、年 1 回以上、手順の有効性を確認する。

### 第25条（文書の管理）（J.4.5.1〜J.4.5.3）

1. PMS の文書（方針、規程、手順、書式、計画など）は、このシステムの「ドキュメント」で管理する。
2. 文書の作成と改訂は、次のとおりとする。
   1. 作成者が下書きを作り、文書番号、版、制定日・改訂日を記載する。
   2. 規程と方針は代表者が、手順と書式は個人情報保護管理者が承認する。
   3. 承認後に公開し、利用する従業者が閲覧できる状態にする。従業者の確認が必要な文書は、従業員ポータルで署名を集める。
   4. 改訂したときは、改訂履歴に版、改訂日、改訂内容、承認者を記録する。
3. 古い版は廃止の扱いとし、誤って使われないようにする。廃止した版を保存する場合は、廃止版であることがわかるようにする。
4. 個人情報保護管理者は、年 1 回以上、文書が最新で適切かを見直す。
5. 外部から入手した文書（法令、ガイドライン、契約書など）は、入手元と版がわかるように管理する。

### 第26条（記録の管理）（J.4.5.5）

1. PMS の記録は、改ざん、紛失、許可のない閲覧から保護し、次の表の期間保存する。期間を過ぎた記録は、『安全管理規程』（12）に従って廃棄する。

| 記録 | 保存場所 | 保存期間 |
| --- | --- | --- |
| 個人情報管理台帳 | このシステムの「処理活動」 | 最新版を常に保持、旧版は【記録の保存期間】 |
| リスクアセスメント・リスク対応の記録 | このシステムの「リスク」 | 【記録の保存期間】 |
| 法令等一覧と見直しの記録 | このシステムの「ドキュメント」 | 【記録の保存期間】 |
| 目標・年間計画と実施状況 | 「ドキュメント」「タスク」 | 【記録の保存期間】 |
| 任命書・体制図 | 「ドキュメント」 | 任期終了後【記録の保存期間】 |
| 教育の計画・受講記録・理解度テストの結果 | 「ドキュメント」または【記録の保管場所】 | 【記録の保存期間】 |
| 力量の評価記録 | 【記録の保管場所】 | 【記録の保存期間】 |
| 秘密保持誓約書 | 【記録の保管場所】 | 退職後【長期保存の記録の保存期間】 |
| 同意の記録 | 【記録の保管場所】 | 個人情報の利用終了後【記録の保存期間】 |
| 第三者提供・受領の記録 | 【記録の保管場所】 | 『個人情報取扱規程』（11）による |

## 第6章 運用

### 第28条（運用）（J.5.1）

1. 従業者は、この規程と前条の内部規程に従って個人情報を取り扱う。
2. 個人情報保護管理者は、年間計画とリスク対応計画が予定どおり実施されているかを【運用の確認の頻度】に確認し、遅れがあれば担当者に対応を指示する。確認の結果は、このシステムの「タスク」の状態で管理する。

## 第7章 パフォーマンス評価

### 第29条（運用の確認と点検）（J.6.1）

1. 部門責任者は、自部門で規程どおりに個人情報が取り扱われているかを【取扱状況の確認の頻度】に確認し、結果を個人情報保護管理者に報告する。確認には、少なくとも次を含める。
   - 台帳と実際の取扱いが一致しているか
   - 書類・媒体の保管と廃棄、机上・画面の管理
   - アクセス権が業務上必要な人に限られているか
2. 個人情報保護管理者は、年 1 回以上、PMS 全体が規程どおりに運用され、目標が達成されているかを点検する。
3. 確認と点検の結果は、このシステムの「ドキュメント」または【記録の保管場所】に記録する。問題が見つかった場合は、「指摘事項」に登録し、第32条に従って対応する。

### 第30条（内部監査）（J.6.2）

内部監査は、年 1 回以上、『内部監査手順』（17）に従って実施する。

### 第31条（マネジメントレビュー）（J.6.3）

1. 代表者は、年 1 回以上、および重大な事故などが起きたときに、マネジメントレビューを行う。
2. 個人情報保護管理者は、次の事項をまとめて代表者に報告する（インプット）。
   - 前回のマネジメントレビューで指示した事項の実施状況
   - 外部・内部の課題、利害関係者の期待、法令等の変化
   - 目標の達成状況と年間計画の実施状況
   - 運用の確認・点検の結果
   - 内部監査の結果
   - 不適合と是正処置の状況
   - 苦情・相談、開示等の請求等の状況
   - 事故とその対応の状況
   - リスクアセスメントの結果とリスク対応の状況
   - 委託先の監督の状況
   - 改善の機会
3. 代表者は、インプットをもとに、次の事項を判断し、指示する（アウトプット）。
   - 方針、目標、規程の見直しの要否
   - 改善の機会と PMS の変更の要否
   - 必要な資源
4. マネジメントレビューの議事録（日時、出席者、インプット、代表者の判断と指示）を作り、このシステムの「ドキュメント」に記録する。指示した事項は「タスク」に登録して進捗を管理する。

## 第8章 改善

### 第32条（不適合と是正処置）（J.7.1）

1. 内部監査、運用の確認・点検、苦情、事故などで不適合が見つかったときは、このシステムの「指摘事項」に登録する。
2. 個人情報保護管理者は、関係する部門責任者とともに次の手順で対応する。
   1. 不適合の内容を確認し、必要な修正を直ちに行う。
   2. 原因を調べ、同様の不適合がほかにないかを確認する。
   3. 再発を防ぐための是正処置を決め、担当者と期限を定めて実施する。
   4. 期限後に、是正処置の効果を確認する。
   5. 必要に応じて、リスクアセスメント、規程、教育の内容を見直す。
3. 不適合の内容、原因、是正処置、効果の確認の結果は、「指摘事項」に記録し、代表者に報告する。

### 第33条（継続的改善）（J.7.2）

個人情報保護管理者は、運用の確認・点検、内部監査、マネジメントレビューの結果、苦情、事故の教訓をもとに、PMS の適切性と有効性を継続的に改善する。改善の内容は、このシステムの「ドキュメント」または「タスク」に記録する。

## 第9章 苦情・相談

### 第34条（苦情・相談への対応）（J.11.1）

1. 当社は、個人情報の取扱いに関する苦情・相談を受け付ける窓口として【問合せ窓口】を設け、外部向けの方針や公表文に記載する。
2. 苦情・相談の受付、対応、記録は、『開示等の請求・苦情相談への対応手順』（14）による。

## 第10章 雑則

### 第35条（違反に対する措置）

従業者がこの規程または関連する内部規程に違反した場合は、就業規則【就業規則の該当条項】に従って懲戒の対象とする。派遣社員や業務委託の者については、契約に従って対応する。

### 第36条（改廃）

この規程の改廃は、個人情報保護管理者が起案し、代表者が承認する。
