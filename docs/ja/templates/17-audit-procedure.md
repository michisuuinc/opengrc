# 内部監査手順

| 項目 | 内容 |
| --- | --- |
| 文書番号 | 【文書番号】 |
| 版 | 第 1 版 |
| 制定日 | 【制定日】 |
| 承認者 | 【代表者氏名】 |
| 対応する J 番号 | J.6.2 |

※ 『個人情報保護マネジメントシステム規程』（10）の第30条に基づく手順です。用語の意味は同規程の第3条によります。
※ このシステムの「監査」に監査ごとの記録を作り、見つかった問題は「指摘事項」に登録して是正処置まで追跡します。

## 1. 目的

この手順は、【会社名】（以下「当社」という）の PMS が JIS Q 15001、当社の規程、法令等に適合し、有効に運用されているかを確かめるための内部監査の進め方を定める。

## 2. 役割

| 役割 | 担当者 | 責任 |
| --- | --- | --- |
| 代表者 | 【代表者氏名】 | 監査計画の承認、監査結果の報告を受けて必要な指示を出す |
| 個人情報保護監査責任者 | 【個人情報保護監査責任者】 | 監査計画の作成、監査員の選定、監査の統括、監査報告書の作成と報告 |
| 監査員 | 【監査員】 | チェックリストの作成、監査の実施、指摘事項の記録 |
| 被監査部門の責任者 | 各部門責任者 | 監査への協力、是正処置の実施 |
| 個人情報保護管理者 | 【個人情報保護管理者】 | 是正処置の統括、PMS 全体（管理部門）としての被監査 |

## 3. 監査計画

1. 個人情報保護監査責任者は、毎年【計画策定月】に年間の監査計画を作り、代表者の承認を得る。
2. 内部監査は、年 1 回以上行う。監査対象は、1 年の間にすべての部門と PMS のすべての要求事項（J.1〜J.11 に対応する規程と運用）を含むようにする。
3. 監査計画には、次の事項を定める。
   - 監査の目的と範囲（対象部門、対象とする規程・J 番号）
   - 監査の基準（JIS Q 15001、当社の規程、法令等）
   - 実施時期と部門ごとの日程
   - 監査員
4. 前回の監査で不適合が多かった部門、事故が起きた部門、業務や体制が大きく変わった部門は、重点的に監査する。
5. 承認した監査計画は、このシステムの「監査」に登録し、計画書を添付する。

## 4. 監査員の選定

1. 個人情報保護監査責任者は、『教育規程』（16）で定める力量を持つ者の中から監査員を選ぶ。
2. 監査員は、自分の所属する部門や、自分が担当する業務を監査してはならない。
3. 個人情報保護監査責任者の所属部門や、個人情報保護監査責任者自身が関わる業務は、別の監査員が監査する。
4. 社内で独立した監査員を確保できない場合は、外部の専門家に監査の一部を依頼してよい。その場合も、監査の責任は個人情報保護監査責任者が持つ。

※ 少人数の会社では、2 人で互いの部門を監査する「相互監査」が現実的です。

## 5. チェックリストの作成

1. 監査員は、監査の前に、対象部門と範囲に合わせたチェックリストを作る。
2. チェックリストには、確認する項目、根拠となる規程・J 番号、確認の方法（質問、記録の確認、現場の観察）を書く。
3. 前回の監査の指摘事項と、その是正処置の効果の確認を必ず含める。
4. 個人情報保護監査責任者は、チェックリストを確認してから監査に使わせる。

## 6. 監査の実施

1. 監査員は、監査の日程と範囲を、【1週間】前までに被監査部門に知らせる。
2. 監査員は、チェックリストに沿って、質問、記録や証跡の確認、現場の観察で確認する。確認した内容と証跡を、チェックリストに記録する。
3. 確認では、規程があるかだけでなく、規程どおりに運用されているか（記録が残っているか、台帳と実際の取扱いが一致しているかなど）を見る。
4. 監査の最後に、被監査部門の責任者に指摘事項を説明し、事実に誤りがないかを確認する。

## 7. 指摘事項の分類

監査で見つかった問題は、次のとおり分類する。

| 分類 | 内容 | 対応 |
| --- | --- | --- |
| 不適合 | JIS Q 15001、当社の規程、法令等の要求を満たしていない | 是正処置が必要 |
| 観察事項 | 現時点では不適合ではないが、放置すると不適合になるおそれがある | 対応の要否を被監査部門が検討する |
| 改善の機会 | 要求は満たしているが、より良くできる点 | 任意で対応する |

※ 不適合のうち、PMS の仕組みが機能していないもの（例：内部監査やマネジメントレビューが行われていない）を「重大な不適合」として区別してもかまいません。

## 8. 監査の報告

1. 監査員は、指摘事項をこのシステムの「指摘事項」に登録し、該当する監査に紐付ける。
2. 個人情報保護監査責任者は、監査の終了後【2週間】以内に監査報告書を作り、代表者に報告する。報告書には、次の事項を書く。
   - 監査の日時、範囲、監査員、被監査部門
   - 監査の基準
   - 指摘事項の一覧（分類、内容、根拠）
   - PMS の適合性と有効性についての総合的な所見
3. 監査報告書は、このシステムの「監査」に添付する。報告書の写しを個人情報保護管理者に渡す。

## 9. 是正処置の依頼とフォローアップ

1. 個人情報保護監査責任者は、不適合について、個人情報保護管理者と被監査部門の責任者に是正処置を依頼する。
2. 被監査部門の責任者は、『個人情報保護マネジメントシステム規程』（10）の第32条に従い、原因を調べ、是正処置の内容と期限を決めて「指摘事項」に記録する。期限は、原則として依頼から【1か月】以内とする。
3. 個人情報保護監査責任者または監査員は、期限後に是正処置が実施され、効果があることを確認する。確認の結果を「指摘事項」に記録し、完了したら状態を「完了」にする。
4. 効果が不十分な場合は、再度の是正処置を依頼する。
5. 観察事項と改善の機会は、被監査部門が対応の要否を検討し、その結果を「指摘事項」に記録する。
6. 監査の結果と是正処置の状況は、マネジメントレビューのインプットとして報告する。
