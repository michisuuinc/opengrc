# ひな形の変数と生成ツール

ひな形（`NN-*.md`）の【 】と条件分岐を、生成ツール `ja-docgen` で埋めるための一覧です。会社ごとの値を設定ファイル（YAML）に書いてツールを実行すると、18 本の完成版（Markdown）ができます。

## 使い方

```sh
# 例の設定ファイルをコピーして、自社の値に書き換える
cp docs/ja/templates/config.example.yaml 自社.yaml

# 完成版を出力する（埋まっていない項目があれば、出力せずに一覧を表示する）
go run ./cmd/ja-docgen -config 自社.yaml -out 出力先

# ひな形だけを検査する（CI でも実行）
go run ./cmd/ja-docgen -check
```

- 自社の値を入れた設定ファイルと完成版は、公開リポジトリに置かないでください。
- 設定ファイルにない項目や、選べない値を書くと、エラーになります。
- 日付は `2026-11-01` の形式で書きます。完成版では「2026年11月1日」になります。改訂日を省くと、制定日と同じになります。

## ひな形の書き方

| 書き方 | 完成版での扱い |
| --- | --- |
| `【変数名】` | 設定ファイルの値（なければ既定値）に置き換える。値がなければエラー |
| `【記入：ラベル】` | 書式を使うたびに書く欄。「＿＿＿＿＿＿（ラベル）」として残す |
| `【文書番号】` | 接頭辞とファイル名の番号から作る（例：`PMS-10`） |
| `<!-- if 選択=値 -->` … `<!-- else -->` … `<!-- endif -->` | 選択に合う側だけを残す。入れ子にできる |
| `<!-- list 一覧名 -->` | 設定ファイルの一覧から表の行を作る |
| 行頭が「※」の行 | 作成者向けの注記として削除する |
| `## N. ` の見出し | 節を削除しても番号が飛ばないよう、振り直す |

消える側のブロックにある変数は、入力しなくてもかまいません。

## 記入欄（完成版でも空欄のまま）

書式（30〜35）の、使うたびに書く欄は `【記入：…】` にしています。会社や管理者の情報は、上の変数で埋まります。同意書（30）の「第三者提供」「委託」「容易に気づかない方法による取得」は、取得の場面ごとに違うため、☐ の段落を残しています。用紙を作るときに、該当する段落を選んでください。
