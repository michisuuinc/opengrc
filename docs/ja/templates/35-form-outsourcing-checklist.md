## 2. 評価項目

評価：適＝基準を満たす、否＝基準を満たさない、該当なし＝この委託には関係しない

| No. | 評価項目 | 判定基準 | 評価 | 確認した資料・備考 |
| --- | --- | --- | --- | --- |
| 1 | 認証の取得 | プライバシーマーク又は ISMS（ISO 27001）の認証を取得し、有効期限内である。取得していない場合は、No.2〜11 で同等の水準を確認する | 適・否・該当なし | |
| 2 | 管理体制 | 個人情報の管理責任者が定められ、責任と権限が明確である | 適・否・該当なし | |
| 3 | 規程の整備 | 個人情報の取扱いと安全管理の規程があり、従業者に周知されている | 適・否・該当なし | |
| 4 | 従業者の教育 | 従業者に年 1 回以上の教育を行い、秘密保持の誓約を取っている | 適・否・該当なし | |
| 5 | 物理的安全管理 | 個人情報を扱う区域の入退室管理、書類・機器の施錠保管、確実な廃棄を行っている | 適・否・該当なし | |
| 6 | アクセス制御 | 個人情報へのアクセスを必要な者に限り、ID を共有せず、多要素認証などで認証を強化している | 適・否・該当なし | |
| 7 | 技術的安全管理 | マルウェア対策、ソフトウェアの更新、通信と保存データの暗号化、ログの取得、バックアップを行っている | 適・否・該当なし | |
| 8 | 再委託の管理 | 再委託するときは事前に当社の承認を得る。再委託先にも同等の義務を課し、監督している | 適・否・該当なし | |
| 9 | 事故時の対応 | 漏えい等の際に、当社へ直ちに報告する体制と手順がある | 適・否・該当なし | |
| 10 | 過去の事故 | 過去【3】年以内に重大な漏えい等がない。ある場合は、再発防止策が実施されている | 適・否・該当なし | |
| 11 | 返却・消去 | 契約終了時に個人情報を返却又は消去し、消去を証明できる | 適・否・該当なし | |
| 12 | 外国でのデータの保管 | データを保管・処理する国が明らかである。外国の場合は、その国の個人情報の保護に関する制度を当社が把握している | 適・否・該当なし | 保管する国：【国名】 |
| 13 | 契約 | 『個人情報の取扱いに関する覚書』（33）の内容を含む契約を結んでいる（又は結ぶ予定である） | 適・否・該当なし | |
