## 3. 開示等の請求等の手続き

ご本人またはその代理人は、当社の保有個人データについて、次のご請求ができます（以下「開示等の請求等」といいます）。

- 利用目的の通知
- 開示（電磁的記録での提供を含みます）
- 内容の訂正、追加、削除
- 利用の停止、消去
- 第三者への提供の停止
- 第三者提供記録（当社が個人データを第三者に提供したとき、または第三者から受け取ったときに作成した記録）の開示

### 3.1 請求先

| 項目 | 内容 |
| --- | --- |
| 窓口 | 【問合せ窓口】 |
| 郵送先 | 〒【郵便番号】 【所在地】 【会社名】 【問合せ窓口】 宛 |
| メールアドレス | 【メールアドレス】 |
| 受付時間 | 【受付時間】 |

※ 窓口での来社受付やウェブフォームでの受付を行う場合は追記します。

### 3.2 提出していただく書類

1. 当社所定の「開示等請求書」
2. ご本人であることを確認するための書類（3.3 参照）
3. 代理人によるご請求の場合は、3.4 の書類

「開示等請求書」は、このページからダウンロードするか、窓口にご請求ください。郵送の場合は、配達の記録が残る方法でお送りいただくことをおすすめします。

### 3.3 ご本人の確認方法

次のいずれかの書類の写しを同封してください。

- 運転免許証、パスポート、マイナンバーカード（表面のみ）、在留カードなど、顔写真付きの公的な証明書 1 点
- 顔写真のない公的な証明書（健康保険の資格確認書、住民票の写しなど）2 点

本籍地、保険者番号などの記載がある場合は、その部分を塗りつぶしてください。マイナンバー（個人番号）が記載された面は送らないでください。

当社にご登録のメールアドレスやアカウントからのご請求の場合は、【例：ログインしたうえでの手続き、登録情報との照合】によって確認することがあります。

※ 本人確認のために求める書類は、必要以上に多くしないでください。サービスの利用者には、ログインなどオンラインで確認する方法を用意すると負担が減ります。

### 3.4 代理人によるご請求

代理人がご請求される場合は、3.3 の書類（代理人ご本人のもの）に加えて、次の書類を同封してください。

| 代理人の種類 | 必要な書類 |
| --- | --- |
| 未成年者または成年被後見人の法定代理人 | 戸籍謄本、登記事項証明書など、法定代理権を確認できる書類 |
| ご本人から委任を受けた代理人 | ご本人の署名・押印のある委任状、ご本人の印鑑登録証明書（委任状の印と同じもの） |

※ 弁護士が代理人の場合は、委任状と弁護士登録番号の確認で足りるとする運用もあります。自社の運用に合わせて書き換えます。

### 3.5 手数料と支払方法

| 請求の種類 | 手数料 |
| --- | --- |
| 利用目的の通知、開示、第三者提供記録の開示 | 1 回のご請求につき【手数料（例：1,000 円）】 |
| 訂正・追加・削除、利用停止・消去、第三者提供の停止 | 無料 |

手数料は、【支払方法（例：同額の郵便定額小為替を請求書に同封、または当社指定の口座への振込（振込手数料はご負担ください））】でお支払いください。手数料が不足している場合や同封されていない場合は、ご連絡のうえ、不足分のお支払いをお願いします。【お支払いがないまま【期間】を過ぎたときは、ご請求がなかったものとして扱います。】

※ 手数料は、実費を考えて合理的と認められる範囲で決めます。無料にしてもかまいません。

### 3.6 回答の方法

1. ご請求を受け付けた後、遅滞なく調査し、ご本人の住所あてに書面で回答します。
2. 開示は、ご請求の際にご指定いただいた方法（電磁的記録の提供、書面の交付、【その他の方法】）で行います。電磁的記録は、【形式（例：PDF または CSV のファイルを、パスワードを付けてメールで送付、またはダウンロード用 URL を通知）】でお渡しします。ご指定の方法では費用が著しくかかる場合や、その方法での開示が難しい場合は、書面の交付で開示し、その旨をお知らせします。
3. 次のいずれかに当たるときは、全部または一部を開示しないことがあります。その場合は、その旨と理由をお知らせします。なお、この場合も手数料はお返ししません。
   - ご本人または第三者の生命、身体、財産その他の権利利益を害するおそれがあるとき
   - 当社の業務の適正な実施に著しい支障を及ぼすおそれがあるとき
   - 開示することが他の法令に違反することになるとき
4. 訂正・追加・削除、利用停止・消去、第三者提供の停止のご請求は、調査の結果に基づいて対応し、対応の内容（対応しない場合はその旨と理由）をお知らせします。

※ 利用停止・消去と第三者提供の停止は、違法な取扱いがある場合のほか、当社が利用する必要がなくなった場合、漏えい等の報告が必要な事態が起きた場合、ご本人の権利や正当な利益が害されるおそれがある場合にも請求できます。

## 4. 保有個人データの安全管理のために講じた措置

当社は、保有個人データの漏えい、滅失、毀損を防ぐため、次の措置を講じています。

| 区分 | 主な措置 |
| --- | --- |
| 基本方針の策定 | 個人情報保護方針を定め、公表しています。 |
| 規律の整備 | 取得、利用、保存、提供、削除・廃棄などの段階ごとに、取扱いの方法と責任者を規程で定めています。 |
| 組織的安全管理措置 | 個人情報保護管理者を置き、取り扱う従業者と取り扱う情報の範囲を明確にしています。規程に反する事実や事故を把握したときの報告の流れを定め、定期的に内部監査を行っています。 |
| 人的安全管理措置 | 従業者に定期的な教育を行い、秘密保持に関する誓約書を取得しています。 |
| 物理的安全管理措置 | 個人データを取り扱う区域の入退室を管理し、端末や書類の盗難・紛失を防ぐ措置を講じています。 |
| 技術的安全管理措置 | アクセスできる人を限定し、認証と権限の管理を行っています。外部からの不正アクセスや不正なソフトウェアから守る仕組みを導入しています。 |
| 外的環境の把握 | 【国名】にある【事業者の種類（例：クラウドサービスの提供者）】のサービスで個人データを保存しています。その国の個人情報保護の制度を把握したうえで、安全管理措置を講じています。 |

※ 公表することで安全管理に支障が出る事項（使っている製品名や具体的な設定など）は、書かなくてかまいません。お問い合わせがあれば遅滞なく回答します。
※ 外国で個人データを取り扱っていない場合は、「外的環境の把握」の行を「国内でのみ保存しています」などに書き換えます。
