# 開示等の請求・苦情相談への対応手順

※ 社外に公表する手続き（「保有個人データに関する事項の公表」（21））と、受付方法、提出書類、手数料、本人確認の方法を一致させてください。

## 1. 目的

この手順は、本人からの開示等の請求等と、個人情報の取扱いに関する苦情・相談に、法令と「個人情報保護方針」に沿って、遅滞なく適切に対応するための方法を定める。

## 2. 適用範囲

当社の保有個人データに関する次の請求（以下「開示等の請求等」という）と、個人情報の取扱いと PMS に関する苦情・相談に適用する。

- 利用目的の通知
- 開示（電磁的記録による提供を含む）
- 訂正・追加・削除
- 利用停止・消去
- 第三者提供の停止
- 第三者提供記録の開示

委託を受けて取り扱う個人データに関する請求を受けたときは、委託元との契約に従い、速やかに委託元に連絡する。

## 3. 役割

| 役割 | 担当 | 責任 |
| --- | --- | --- |
| 窓口担当者 | 【問合せ窓口】の担当者 | 受付、本人確認、記録、本人との連絡 |
| 対象部門の責任者 | 対象の個人データを管理する部門の責任者 | 該当データの調査、訂正・削除などの実施 |
| 個人情報保護管理者 | 【個人情報保護管理者】 | 対応方針の決定、不開示・一部不開示の判断、回答の承認 |
| 代表者 | 【代表者氏名】 | 重大な苦情、訴訟のおそれがある案件の最終判断 |

## 4. 受付

1. 窓口担当者は、郵送、メール、【その他の受付方法】で請求を受け付ける。電話や口頭での請求には、「開示等請求書」（34）の提出を案内する。
2. 窓口担当者は、受付日、請求者、請求の種類、受付方法を、このシステムの「本人からの請求」に登録する。受付日は、請求書が当社に届いた日とする。
3. 窓口以外の従業者が請求や苦情を受けたときは、自分で回答せず、当日中に窓口担当者に引き継ぐ。
4. 請求の内容が特定できないときは、本人が対象を特定できるよう、当社が保有する個人データの区分などの情報を示して補正を求める。

## 5. 本人確認

1. 窓口担当者は、21 に定める書類で、請求者が本人であることを確認する。
2. 確認に必要な範囲を超えて書類を求めない。本籍地、マイナンバーなどが塗りつぶされていない場合は、確認後にその部分を塗りつぶすか、写しを廃棄する。
3. 当社のサービスの利用者からの請求は、登録済みのアカウントへのログイン、登録情報との照合などで確認してもよい。
4. 書類が不足しているときは、本人に追加を求め、その日を記録する。確認できるまでは、対応期限の計算を止めて扱う。

※ 期限の計算を止める扱いは社内の目標期限に関するものです。法令上の「遅滞なく」の要請は残るため、追加依頼は速やかに行ってください。

## 6. 代理人の確認

1. 代理人からの請求は、代理人の本人確認書類と、代理権を確認できる書類（法定代理人は戸籍謄本や登記事項証明書など、任意代理人は本人の委任状と印鑑登録証明書）で確認する。
2. 代理権に疑いがあるときは、本人に直接、代理の意思を確認する。
3. 回答は、原則として本人の住所に送る。代理人への送付を求められたときは、個人情報保護管理者が判断する。

## 7. 対応期限

1. 開示等の請求等には、遅滞なく対応する。
<!-- if 手数料=あり -->
2. 社内の目標として、受付から【開示等の回答目標日数】日以内に回答する。本人確認書類や手数料の不足を補ってもらうのを待つ期間は、この日数に含めない。
<!-- else -->
2. 社内の目標として、受付から【開示等の回答目標日数】日以内に回答する。本人確認書類の不足を補ってもらうのを待つ期間は、この日数に含めない。
<!-- endif -->
3. 目標期限内に回答できない見込みのときは、期限の前に、本人にその理由と回答の予定日を知らせる。
4. 苦情・相談には、受付から【苦情の一次回答の営業日数】営業日以内に一次回答を行う。

## 8. 調査と対応の決定

1. 対象部門の責任者は、該当する保有個人データの有無と内容を調べ、窓口担当者に報告する。
2. 個人情報保護管理者は、調査の結果に基づき、請求の種類ごとに次のとおり対応を決める。

| 請求の種類 | 対応 |
| --- | --- |
| 利用目的の通知 | 利用目的を通知する。公表済みで明らかな場合などは、通知しないことがある |
| 開示 | 本人が指定した方法（電磁的記録の提供、書面の交付など）で開示する。指定の方法が多額の費用を要するなど難しい場合は書面で開示し、その旨を知らせる |
| 第三者提供記録の開示 | 保存している提供・受領の記録を、開示と同じ方法で開示する |
| 訂正・追加・削除 | 内容が事実でないと確認できたときは、利用目的の達成に必要な範囲で訂正などを行う |
| 利用停止・消去、第三者提供の停止 | 法令の要件に当たると確認できたときは、利用停止などを行う。多額の費用を要するなど難しい場合は、本人の権利利益を守るための代わりの措置をとる |

3. 利用停止・消去、第三者提供の停止は、違法な取扱いのほか、利用する必要がなくなった場合、漏えい等の報告対象となる事態が起きた場合、本人の権利または正当な利益が害されるおそれがある場合にも請求できることに注意する。

## 9. 不開示・一部不開示の判断と理由の説明

1. 次のいずれかに当たるときは、個人情報保護管理者が、全部または一部を開示しないと判断できる。
   - 本人または第三者の生命、身体、財産その他の権利利益を害するおそれがある
   - 当社の業務の適正な実施に著しい支障を及ぼすおそれがある
   - 開示することが他の法令に違反する
2. 不開示・一部不開示、または請求に応じない（訂正などを行わない場合を含む）と決めたときは、その旨と理由を本人に知らせる。理由は、本人が納得できるよう具体的に書く。
3. 判断に迷うときは、【外部の相談先】に相談する。
4. 判断の内容と理由は、「本人からの請求」に記録する。

## 10. 手数料

<!-- if 手数料=あり -->
1. 利用目的の通知、開示、第三者提供記録の開示には、『保有個人データに関する事項の公表』（21）に定める手数料を求める。訂正・追加・削除、利用停止・消去、第三者提供の停止には手数料を求めない。
2. 手数料が不足しているときは、本人に連絡して不足分を求め、その日を記録する。
3. 受け取った手数料は、【経理の手続き】に従って処理する。
<!-- else -->
開示等の請求等には、手数料を求めない。
<!-- endif -->

## 11. 回答と記録

1. 窓口担当者は回答文を作り、個人情報保護管理者の承認を得てから送る。
2. 電磁的記録で開示するときは、ファイルにパスワードを付ける、ダウンロードの期限を設けるなど、送付中の漏えいを防ぐ措置をとる。パスワードは別の経路で知らせる。
3. 回答後、窓口担当者は、回答日、対応内容、回答方法、不開示の理由を「本人からの請求」に記録し、状態を「完了」にする。請求書と本人確認書類の写しは【記録の保管場所】に【記録の保存期間】保存する。
4. 訂正、削除、利用停止などを行ったときは、その個人データを提供した委託先や第三者にも必要に応じて知らせ、結果を記録する。

## 12. 苦情・相談の受付と対応

1. 苦情・相談は、窓口（【問合せ窓口】）で受け付ける。窓口以外で受けたときは、当日中に窓口担当者に引き継ぐ。
2. 窓口担当者は、受付日、申出者、内容、対象の部門を「本人からの請求」に記録する。
   種類は「苦情」を選ぶ。相談の場合も「苦情」を選び、内容の先頭に「相談」と書く（このシステムには相談の種類がないため）。
3. 窓口担当者は、対象部門の責任者と事実を確認し、対応案を作って個人情報保護管理者の承認を得る。
4. 申出者に、確認した事実と対応の内容を説明する。すぐに結論が出ないときは、経過と見通しを知らせる。
5. 苦情の原因が当社の取扱いの不備にあるときは、指摘事項として「指摘事項」に登録し、是正処置を行う。
6. 対応の経過と結果を記録し、状態を「完了」にする。

## 13. エスカレーション

窓口担当者は、次の場合、ただちに個人情報保護管理者に報告する。個人情報保護管理者は、必要に応じて代表者に報告する。

- 不開示・一部不開示、または請求に応じない見込みの場合
- 目標期限内に回答できない見込みの場合
- 漏えい等の事故が疑われる場合（「漏えい等の緊急時対応手順」（15）に従う）
- 申出者が訴訟、行政機関への申出、報道機関への連絡などを示している場合
- 同じ内容の苦情が繰り返される場合、または重大な苦情の場合

## 14. 見直し

個人情報保護管理者は、開示等の請求等と苦情・相談の件数、対応日数、不開示の件数を年に 1 回以上集計し、マネジメントレビューに報告する（「個人情報保護マネジメントシステム規程」（10））。

※ 改正法の施行時に見直す：2026 年に成立した改正法の施行により、開示等の請求等の要件や手続きが変わる可能性があります。
