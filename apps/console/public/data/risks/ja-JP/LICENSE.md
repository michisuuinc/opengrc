# リスクテンプレート（日本語版）

[risks.json](risks.json) は、Probo Inc. のリスクテンプレート（[../risks.json](../risks.json)）を MICHISUU Inc. が日本語に翻訳したものです。元のデータと同じく、Creative Commons Attribution-ShareAlike 4.0 International（CC BY-SA 4.0）ライセンスで提供します。

## 変更点

- 82 件すべての分類（category）、名前（name）、説明（description）を日本語に翻訳しました。件数と並び順は元のデータと同じです。
- 分類「Health」は、含まれるリスクがすべて HIPAA と患者データに関するものなので「医療」と訳しました。
